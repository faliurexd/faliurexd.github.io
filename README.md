# faliurexd | GitHub Profile

A futuristic, hacker-inspired personal website showcasing my journey as a developer.

## Live Demo

**[View Live Site](https://faliurexd.github.io)**

## Features

- **3D Cosmic Background** — Swirling wireframe planets with Three.js
- **Wave Animation** — Mesmerizing water wave effects at the bottom
- **Glitch Typography** — Neon-glowing text with cyberpunk aesthetics
- **Interactive Elements** — Hover effects, parallax mouse tracking, typing animations
- **Responsive Design** — Optimized for all screen sizes
- **Scroll Animations** — Sections reveal as you scroll down

## Tech Stack

- HTML5
- CSS3 (Custom Properties, Animations, Grid)
- JavaScript (ES6+)
- Three.js (3D Graphics)
- Google Fonts (Orbitron, Share Tech Mono)

## Deployment

This site is deployed using **GitHub Pages**.

### How to Deploy

1. Push this repository to GitHub
2. Go to **Settings** > **Pages**
3. Under **Source**, select **Deploy from a branch**
4. Choose **main** branch and **/ (root)** folder
5. Click **Save**
6. Your site will be live at `https://faliurexd.github.io`

### Quick Commands

```bash
# Initialize git repo
git init

# Add all files
git add .

# Commit
git commit -m "Initial commit: futuristic GitHub profile"

# Add remote (replace with your repo URL)
```
